# 智售引擎 3 分钟演示与答辩脚本

## 一句话定位

智售引擎让社区小店用一部手机完成基础进销存，并把顾客扫码提问直接转化为补货、跟进和促销行动。

## 演示流程

1. 打开本机 Demo 首页，说明无需账号、云端密钥或专用硬件即可运行；商家端和顾客端共用同一套门店数据。
2. 进入顾客端，提问“水龙头怎么安装”。智购顾问基于商品资料给出位置、价格和安装建议。
3. 返回“经营机会”。智店管家识别到顾客关注的水龙头库存低于安全库存，生成优先补货建议；说明这就是顾客信号到经营行动的双 Agent 协同。
4. 再演示两条电工胶带咨询，点击“生成公开促销”。打开顾客端，展示促销即时可见。
5. 回到商家端录入销售，展示库存自动扣减、库存预警和周报；补充可用语音/文字说“查胶带库存”“改胶带价格为 5”。

## 创新点表达

- **双 Agent 经营闭环**：智购顾问不是独立聊天窗口，顾客需求会同步到智店管家并变成明确的经营建议。
- **离线可演示、云端可扩展**：本机规则引擎和种子数据确保现场稳定；配置 Supabase 后同一界面可切换到多门店云端数据与平台托管 AI。
- **小微门店低门槛**：二维码即顾客入口，手机即可管理商品、销售、库存与促销，不要求扫码枪、收银系统或复杂部署。

## 真实技术说明

- 前端：Vue 3 + TypeScript + Ionic，使用 Capacitor 适配 Android/iOS，Web/PWA 为主要 Demo 交付方式。
- 数据：本地使用 Capacitor Preferences；可选 Supabase Postgres、Auth、Storage 和 Edge Functions。
- AI：无密钥时使用可解释的商品、库存和场景规则；云端配置后由 Edge Function 调用平台托管模型和知识检索。

## 边界说明

当前版本为竞赛 Demo，不包含支付、会员、供应商自动下单、复杂工作流编排或多员工协同。这些是验证小微零售 AI 改造价值后的后续扩展方向。
