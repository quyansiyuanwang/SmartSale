# 厨房水龙头安装说明

## 安装前准备

- 关闭总水阀，打开旧水龙头放空管内余水。
- 准备活动扳手、生料带、抹布和接水盆。
- 确认冷热进水管方向，冷水通常接右侧、热水接左侧。

## 安装步骤

1. 用扳手拆下旧水龙头，清洁台面和进水接口。
2. 在螺纹接口顺时针缠绕生料带 8 到 12 圈。
3. 将新水龙头和密封垫装入孔位，从台面下方拧紧固定螺母。
4. 连接冷热水管，注意不要将冷、热水接反。
5. 缓慢打开总水阀，检查接口是否渗漏。

## 安全提示

如需拆改墙内管路或发现持续漏水，请关闭水阀并联系专业安装人员。通水测试时先小流量检查，再完全打开阀门。
