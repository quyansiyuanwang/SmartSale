# 演示素材使用说明

这组素材用于竞赛 Demo 或本机 Supabase 联调，不代表真实门店的进货清单。

## 商品批量导入

1. 登录商家端并完成建店。
2. 打开“我的 -> 门店服务与二维码”。
3. 先点击“下载模板”确认当前字段格式，再选择 `商品批量导入示例.csv`。
4. 等待导入成功提示，进入“商品”页检查价格、库存和货架位置。
5. 需要触发库存预警时，使用示例中的“电工胶带”（库存 10、安全库存 3）或“冲击钻”（库存 3、安全库存 2）。

系统按整批校验：任意一行有错误时不会部分写入。支持字段为：商品名称、条码、分类、进价、售价、库存、安全库存、货架位置、商品描述；一次最多导入 1000 行。

## 知识库资料

连接 Supabase 且配置 Embedding 后，在同一页面的“知识库”卡片上传 `知识库-水龙头安装说明.md`，等待解析完成后点击“发布”。随后在顾客端提问“水龙头怎么安装”，即可演示知识库检索与导购回答。

未配置 Embedding 时不要把上传失败当作系统故障；使用内置规则知识库和离线 Demo 仍可完成比赛演示。

## 推荐演示顺序

商品导入 → 顾客查看公开商品 → 顾客提问水龙头安装 → 商家查看顾客咨询 → 商家执行“查胶带库存” → 录入销售触发库存预警。
