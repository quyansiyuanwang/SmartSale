# 商家端使用指南

## 如何进入商家端

1. 推荐从 GitHub Release 下载并安装商家 Android APK；电脑管理时可在浏览器打开 `https://app.example.com/login`。
2. 已有账号：输入注册邮箱和密码，点击“登录后台”。
3. 新商家：切换到“创建门店”，输入邮箱和至少 8 位密码。
4. 若平台启用了邮箱验证，先完成邮件确认，再回到登录页登录。
5. 首次登录会进入“创建你的门店”向导。填写门店名称、地址、电话和营业时间后提交。

建店成功后系统会自动创建门店 slug、owner 权限和随机顾客访问令牌，随后跳转到“门店服务设置”。同一账号再次登录会直接进入已有门店后台。

Android APK 与 Web/PWA 使用同一 Supabase 平台配置。安装包由 CI 的 Android 制品或正式 Release 提供；顾客不需要安装 APK。

> 当前实现中，一个账号会加载其查询结果中的第一家门店；一线人员不要用同一账号创建多家门店。多门店切换界面尚未实现。

## 建店后的上线操作

1. 打开“我的 -> 门店服务与二维码”。
2. 补全门店资料、营业时间和顾客欢迎语，点击“保存门店资料”。
3. 在商品页逐个新增商品，或在设置页下载 CSV 模板后批量导入。仓库提供可直接演示的 [商品批量导入示例](demo-materials/商品批量导入示例.csv)，字段和填写规则见 [演示素材使用说明](demo-materials/演示素材使用说明.md)。
4. 确认商品的“已发布”状态、售价、库存和货架位置正确。只有已发布商品会显示给顾客。
5. 在设置页确认“公开售前服务”开关已开启。
6. 下载二维码或复制“顾客入口”，用未登录浏览器实际打开一次。

二维码地址形如 `VITE_APP_PUBLIC_BASE_URL/s/<store-slug>?token=<random-token>`。令牌由服务端保存，直接输入 `/s/<store-slug>` 不会打开顾客端。点击“刷新令牌”后旧二维码立即失效，需要重新下载或打印二维码；仅更新门店资料、商品或促销不会改变令牌。

## 商家端功能说明

| 区域 | 用途 |
| --- | --- |
| 首页 | 开店引导清单（未完成接入步骤时显示）、经营概览、库存和业务快捷入口 |
| 商品 | 新增、编辑、发布商品；维护货架位置、价格和库存。“在顾客端展示（已发布）”关闭后，该商品立即从顾客端目录消失 |
| 销售 | 录入销售，调用服务端 `record_sale` 原子扣减库存。支持三种录入方式：相机扫码（浏览器需支持 `BarcodeDetector` 且页面为 HTTPS/localhost，不支持时按钮自动隐藏）、条码/名称输入后回车选中、语音填入商品名；库存降到安全线以下时页面提醒并语音播报补货 |
| 报表 | 查看销售、利润、热销与滞销数据；可切换本周/上周，滞销商品可一键生成 9 折公开促销 |
| 顾客咨询 | 查看顾客公开问答产生的咨询记录 |
| 经营机会 | 智店管家对库存紧张商品的补货建议，可直接“去补货”到预警页 |
| 门店服务与二维码 | 更新公开资料、暂停服务、下载二维码、批量导入商品、管理促销启停、管理知识库文档 |

## 开店引导

首次使用时，首页会显示“开店引导”清单，按顺序完成三步即可开门营业：完善门店资料 → 录入第一个商品（推荐用设置页的 CSV 模板批量导入）→ 录入第一笔销售。每一步可点击直达对应页面；全部完成后清单自动隐藏。

## 暂停和恢复顾客服务

在“门店服务与二维码”关闭“公开售前服务”，顾客原二维码仍然有效，但会显示“门店服务暂时不可用”。恢复时重新打开开关即可。该操作不会删除商品、咨询或二维码。本机 Demo 模式中该开关同样可用，可用于现场演示顾客端暂停页。

## 促销管理

“门店服务与二维码”页的“促销活动管理”卡片列出全部促销，开关实时控制顾客端“今日优惠”的展示：关闭后顾客端立即隐藏，重新打开即恢复。促销也可以在“经营机会”或“报表”页针对顾客咨询热点/滞销商品一键生成。

## 知识库（顾客问答资料）

“门店服务与二维码”页的“知识库”卡片用于维护顾客售前问答引用的资料：

1. 点击“上传知识文档”，选择 PDF、DOCX、TXT 或 Markdown 文件；单文件不超过 10 MB。
2. 上传后系统自动解析、切片并向量化，状态从“处理中”变为“草稿”；解析失败会显示原因，可点击“重新解析”。
3. 点击“发布”后，顾客提问会优先引用该文档内容；点击“撤回”立即停止引用。文档状态不会影响商品问答，仅影响自有资料。
4. 不再需要的文档点击“删除”，同时清理存储文件与向量数据。

上传时系统会将文件在 Storage 中保存为 ASCII 安全路径（例如 `document.md`），但页面和数据库仍保留原始中文文件名，不影响查看和检索。

本机演示模式使用内置示例知识库，此卡片显示说明文字；只有连接平台服务后才可上传。知识库检索依赖平台的 Embedding 配置（见[配置参考](03-configuration.md)）。

竞赛可直接使用仓库中的 [水龙头安装说明](demo-materials/知识库-水龙头安装说明.md) 作为第一份知识库文档；商品导入和知识库上传的完整顺序见 [演示素材使用说明](demo-materials/演示素材使用说明.md)。

## 账号问题

- 忘记密码：在 `/login` 输入邮箱后点击“忘记密码”；邮件链接会回到 `/login`。
- 注册成功但不能直接建店：通常是启用了邮箱确认，请先完成确认邮件。
- 登录后又跳到建店页：该账号在 `store_members` 中没有门店成员关系，需要检查建店函数日志与数据库记录。
