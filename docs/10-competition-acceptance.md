# 竞赛验收与现场演练手册

这份手册用于在没有 Supabase、模型 Key 和专用硬件的情况下完成智售引擎竞赛 Demo 验收。默认演示模式使用本地种子数据、Preferences 存储和规则型知识引擎，断网也可以运行。

需要准备真实商品资料时，可直接使用 [演示素材目录](demo-materials/演示素材使用说明.md) 中的商品 CSV 和知识库文档。

## 一、验收前准备

需要 Node.js 22、PowerShell 和现代浏览器（Chrome 或 Edge）。在项目根目录执行：

```powershell
npm install
npm run lint
npm test
npm run build
```

预期结果：Lint 无错误，单元测试全部通过，生产构建生成 `dist/`。现场演示不需要填写 `.env.demo.local`；如果配置了真实 AI，也必须保留本地降级能力。

## 二、启动 Demo

在一个 PowerShell 窗口运行：

```powershell
npm run demo
```

浏览器打开终端显示的地址，通常是：

```text
http://localhost:5173/demo
```

局域网手机访问时使用终端输出的 `http://<电脑局域网 IP>:5173/demo`。电脑和手机必须连接同一 Wi-Fi，Windows 防火墙需要允许 Node.js/Vite 访问该端口。

## 三、每次演示前重置

优先点击 Demo 首页的“恢复初始演示数据”。也可以进入商家端“我的”页面，点击“重置演示数据”。重置会清除本地商品修改、销售、咨询和促销，避免前一轮演示影响结果。

## 四、推荐 3 分钟演示流程

### 1. 展示双入口

在 `/demo` 首页依次展示“商家端”和“顾客端”两个入口，并说明两端使用同一份门店数据。点击“查看双 Agent 架构”或直接打开 `/architecture`，说明云端五个模块、两个端侧 Agent 和统一代码库。

### 2. 顾客问答驱动商家行动

1. 从 Demo 首页进入“顾客端”，或打开 `/s/demo-store`。
2. 输入问题：`水龙头怎么安装`，提交文本问题。浏览器支持语音时也可点击语音按钮；不支持时使用文本。
3. 确认回答包含安装建议、商品信息或配套工具信息。
4. 返回商家端“经营机会”，确认出现水龙头相关的补货/需求跟进建议。
5. 打开“顾客咨询”，确认问题、回答、时间和“演示模式”标识均可见。

### 3. 重复咨询生成促销

1. 回到顾客端，分别提问：`电工胶带在哪`、`电工胶带多少钱`。
2. 返回“经营机会”，找到电工胶带的“转化机会”。
3. 点击“生成公开促销”，在弹窗点击“确认创建”。
4. 返回顾客端，确认出现“电工胶带 · 顾客推荐”，且促销为公开状态。

### 4. 商家经营指令与库存闭环

1. 进入“报表”，在语音或文本指令中输入 `查胶带库存`，确认返回库存和货架信息。
2. 输入 `改胶带价格为 5`，确认电工胶带售价更新为 5 元。
3. 进入“销售”，录入一笔电工胶带销售，确认库存自动扣减。
4. 当库存低于安全库存时，确认出现库存预警；支持语音播报的浏览器会播放补货提醒。
5. 返回 `/architecture`，点击“演示经营指令”，确认最近一次工作流出现“解析经营指令”“调度智店管家 Agent”“读取库存/报表数据”等事件。
6. 云端模式下进入“门店服务与二维码”，上传一份 TXT/Markdown 知识文档，等待状态变为“草稿”后点击“发布”；顾客问答命中后再点击“撤回”，确认资料不再参与检索。

## 五、架构页验收

打开 `/architecture`，逐项确认：

| 检查项 | 预期结果 |
| --- | --- |
| 云端五模块 | 大模型 API 网关、Agent 工作流引擎、行业知识引擎、关系型数据库、双 Agent 协同中心全部可见 |
| 双 Agent | 智店管家和智购顾问节点可见 |
| 统一代码库 | 显示“全平台统一代码库”，并列出 Android、iOS、鸿蒙 Web、Web |
| 顾客演示 | 点击“演示顾客问答”后显示问题、事件时间线和知识命中 |
| 商家演示 | 点击“演示经营指令”后显示查库存的工作流事件 |
| 状态反馈 | 事件成功后节点变为 RUNNING，协同状态显示 SYNCED |

## 七、Cypress 自动化验收

先确保 Vite Demo 服务运行在 `http://localhost:5173`，然后在另一个窗口执行：

```powershell
npm run test:e2e
```

当前 E2E 覆盖两组场景：

- 架构页展示五个云端模块、双 Agent、统一代码库和两条演示工作流。
- Demo 首页闭环生成顾客咨询、经营机会和公开促销。

如果 Cypress 报二进制未验证或无法启动，依次执行：

```powershell
npx cypress cache clear
npm install
npx cypress install
npx cypress verify
npm run test:e2e
```

若本机 Cypress 版本仍因 `--smoke-test`、`--ping` 参数失败，不要反复修改业务代码，直接按“第四节推荐演示流程”和“第六节人工验收记录表”完成替代验收，并记录 Cypress 环境错误。

## 八、现场故障处理

- 页面打不开：确认 `npm run demo` 仍在运行，并使用终端实际显示的端口。
- 数据异常：点击“恢复初始演示数据”，然后刷新页面。
- 语音不可用：使用同样的文字指令，语音属于渐进增强能力。
- 相机扫码不可用：使用条码/商品名称输入；扫码只在 localhost 或 HTTPS 且浏览器支持 `BarcodeDetector` 时出现。
- 知识库上传或解析失败：确认使用云端模式、文件类型为 PDF/DOCX/TXT/Markdown 且不超过 10 MB；检查 `knowledge-ingest` 日志和 Embedding 密钥。演示模式使用内置知识库，不提供上传入口。
- 局域网手机打不开：检查同一 Wi-Fi、防火墙和电脑 IP；电脑浏览器演示不受此问题影响。
- 真实 AI 超时或失败：确认页面仍返回本地规则回答，继续使用 Mock 演示即可。

## 九、交付前最终命令

```powershell
npm run lint
npm test
npm run build
npm run demo:build
git diff --check
```

将 `dist/`、演示截图、[演示与答辩脚本](../goal/演示与答辩脚本.md) 和本手册一起作为竞赛交付材料。不要把 `.env.demo.local`、Supabase 密钥或任何模型 Key 放入压缩包。
