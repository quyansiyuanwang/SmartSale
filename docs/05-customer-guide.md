# 客户端使用指南

这里的“客户端”指顾客使用的公开 Web/PWA，不需要下载 App 或注册账号。

## 如何进入客户端

顾客有两种等效方式：

1. 扫描商家在“门店服务与二维码”页面下载的二维码（二维码中包含随机访问令牌）。
2. 在手机或电脑浏览器打开商家提供的完整链接：`https://app.example.com/s/<store-slug>?token=<random-token>`。

顾客无需访问 `/login`。`/buyer` 是开发/演示入口；生产环境应以带 slug 的 `/s/<store-slug>` 为唯一可传播地址，否则无法稳定定位到具体门店。

## 顾客可见内容

- 门店名称、地址、营业时间、电话（点击可直接拨号）和欢迎语。
- 已发布商品的名称、分类、售价、库存、货架位置与描述；商品目录可按分类筛选，缺货商品有“暂时缺货”标识。
- 当前启用的促销活动。
- 售前问答：可询问商品位置、价格、替代品、使用方法或场景化清单。

顾客提问后，系统会将咨询记录同步到该门店商家端的“顾客咨询”页面，供门店跟进。

## PWA 安装

在支持 PWA 的手机/桌面浏览器中，打开顾客链接后可使用浏览器“添加到主屏幕”或“安装应用”。安装后图标仍然打开同一个公开链接。PWA 安装依赖 HTTPS，内网 HTTP 地址不能作为正式交付方式。

## 访问异常

| 页面现象 | 含义和处理 |
| --- | --- |
| “未找到此门店” | 二维码/链接错误，或该 slug 不存在；请由商家重新从设置页复制链接 |
| “顾客入口已失效” | 缺少访问令牌，或商家已刷新令牌；请扫描最新二维码/重新获取完整链接 |
| “门店服务暂时不可用” | 商家关闭了公开售前服务或暂停了服务；联系商家恢复 |
| 直接扫码显示站点 404 | 静态站点没有配置 `/s/* -> /index.html` SPA 回退；由部署人员修复 |
| 问答提示服务不可用 | 检查 Edge Function、AI/Embedding 密钥和网络，详见运维手册 |
