# 本机演示指南

本项目可以不配置 Supabase、AI Key 或公网域名完成完整 Demo。默认使用本地种子门店、商品、销售数据和规则型导购回答。

需要真实 AI 时，复制 `.env.demo.local.example` 为 `.env.demo.local`，填写 `DEMO_AI_BASE_URL`、`DEMO_AI_API_KEY`、`DEMO_AI_MODEL`，再运行同一条 `npm run demo`。Key 只保存在运行 Vite 的电脑，不会发给局域网内的顾客浏览器；未配置或调用失败时会自动回退为本地规则回答。

## 启动

```powershell
npm install
npm run demo
```

终端会显示本机与局域网访问地址。电脑浏览器打开 `http://localhost:5173`，会进入 Demo 双入口页。顾客端入口会自动带本机生成的随机 token；直接访问 `/s/demo-store` 会显示“顾客入口已失效”。

- 商家端：库存、销售、报表、顾客咨询和经营机会。
- 顾客端：商品问答、场景化清单和公开促销。
- 一键运行闭环：自动生成“水龙头怎么安装”的顾客咨询，并进入商家的经营机会页。

## 现场演示顺序

1. 在首页点击“一键运行闭环”。系统会预置一条水龙头咨询和两条电工胶带咨询。
2. 在“经营机会”查看由顾客咨询自动生成的补货和促销建议；补货建议可直接点“去补货”跳到库存预警页。
3. 对库存紧张商品标记“已跟进”，并对电工胶带的转化机会创建公开促销。
4. 打开顾客端，确认新促销已经显示。
5. 返回商家端，演示录入销售、库存预警、周报和语音/文字指令：
   - 销售页支持三种录入：相机扫码（`BarcodeDetector`，仅本机 localhost 或 HTTPS 页面可用，按钮会按环境自动隐藏）、条码/名称回车直接选中、语音填入；把商品卖到安全库存以下时会弹窗并语音播报补货提醒。
   - 报表页可切换“本周/上周”，滞销商品可一键生成 9 折公开促销；语音指令支持「查胶带库存」「改胶带价格为 5」「上周热销」。
   - 库存预警页有“语音播报”按钮，可读出全部预警商品。
   - 首页的“开店引导”清单只在门店资料/商品/销售缺失时出现，演示种子数据下保持隐藏；新店铺可现场走一遍三步引导。
6. 需要演示暂停服务时，进入“门店服务与二维码”关闭“公开售前服务”，顾客端刷新后会显示“门店服务暂时不可用”，重新打开即恢复。
7. 需要演示访问控制时，在“门店服务与二维码”点击“刷新令牌”，旧二维码/旧链接立即失效，再下载新二维码验证新入口。

## 手机扫码演示

电脑和手机连接同一 Wi-Fi 后，使用终端输出的 `http://<局域网-IP>:5173` 打开应用。应用会根据当前访问地址生成顾客入口；在“门店服务与二维码”下载二维码后，用手机扫码即可进入顾客端。

若手机无法访问：确认 Windows 防火墙允许 Node.js/Vite 使用端口 `5173`，并确认两台设备在同一局域网。局域网 HTTP 可用于演示，但浏览器的 PWA 安装能力通常需要 HTTPS。

## 重置与云端模式

- Demo 首页和“我的”页均可恢复初始数据；会清空本机的商品修改、顾客咨询和新建促销。
- 需要云端试点时，按 [服务端部署](02-server-deployment.md) 配置 Supabase；普通 `npm run dev` 会自动使用云端配置。
- `npm run demo` 始终使用 `.env.demo` 强制本地演示模式，不会访问商家或顾客的真实数据。
